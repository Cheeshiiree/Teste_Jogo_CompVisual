# Guia de como executar e testar os codigos

## Requisitos
- Python 3.8 ou superior
- Bibliotecas: `numpy`, `pandas`, `pygame`, `random`, `OpenCv`

<!--- Bibliotecas sugeridas nas diretrizes do projeto --->
- `PyOpenGL` para gráficos 3D 
- `Pigame` para desenvolvimento de jogos
- `OpenCV` para processamento de imagens
- `scikit-image` para manipulação de imagens
- `Numpy` para operações matemáticas e manipulação de arrays

<!--- Outras bibliotecas que acho úteis --->
- `Matplotlib` para visualização de dados
- `Pillow` para manipulação de imagens
- `PyQt` para desenvolvimento de interfaces gráficas
- `Pygamezero` para desenvolvimento de jogos 2D
- `Tkinter` para desenvolvimento de interfaces gráficas simples
